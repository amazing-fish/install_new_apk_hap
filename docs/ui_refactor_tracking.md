## 当前 UI 结论

以下内容已经稳定在主线，不需要继续在本文件重复维护实现细节：

- 原生 Tkinter / ttk；`App` 持有状态与任务编排，`ui_layout.py` 负责一次性控件装配。
- 设备列表默认至少 3 行、最多 8 行。
- 页面、设备表、日志滚动条按需出现；内容不溢出时不占空间。
- APK/HAP 下拉框直接承担包名、版本和真实文件名的主显示，不重复第二排摘要。
- 底部安装 / 中止入口固定可达，操作按钮可随宽度换行。
- Harmony APP 日志以单个“获取APP日志”菜单承载乾崑 / Demo 两个目标。
- Android `-t` 不再提供手工 UI 状态；只根据元数据自动决定，未知状态采用可安装优先的安全默认。
