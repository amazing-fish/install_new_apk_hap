第一阶段只迁移显示格式化并接入摘要；保持安装命令、配置 schema、发布版本、刷新联动、全量候选、安装快照及日志时序。执行区和状态栏共享一个当前选择摘要；包摘要显示当前选择，已开始安装的参数仍以点击快照与请求日志为准。

第二阶段只移动装配与现有视觉配置：`ui_layout.build_ui(app)` 在 App 变量初始化后、启动刷新前调用一次，各区只绑定这些变量和现有回调，控件引用继续供 App 使用。`ui_styles` 保持原生 ttk 主题；`ui_display` 的显示语义不变。布局模块无需配置对象或设备服务即可通过同一入口测试。本轮不实施 #34/#47/#48。

本轮不整体合并 #35。#20 的 UDID 目标已由 #21 落地；#23 的日志目标由 #24/#26 及后续修复覆盖，但其 hilog 方案不同，不能当作等价补丁合入。这些旧 PR 保留历史，未自动关闭；后续处置应区分目标已覆盖与实现仍可采用。
